## 🚀 快速开始

### 方式一：使用 Conda 环境（推荐）

如果您已经按照 [Conda 环境设置指南](./conda_environment_setup.md) 创建了环境：

```bash
# 1. 激活 conda 环境
conda activate tradingagents

# 2. 安装项目依赖（如果还没安装）
pip install -e .

# 3. 配置环境变量（见下方配置设置）
# 编辑 .env 文件

# 4. 启动后端服务
python -m app

# 5. 在另一个终端启动前端（可选）
cd frontend
npm install  # 首次运行需要
npm run dev
```

### 方式二：使用虚拟环境

```bash
# 1. 创建虚拟环境
python -m venv venv

# 2. 激活虚拟环境
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# 3. 安装依赖
pip install -e .

# 4. 启动服务
python -m app
```

## 🔧 环境准备

### 必需组件

1. **Python 3.10+**
   ```bash
   python --version  # 应显示 3.10.x 或更高
   ```

2. **MongoDB**（可选，但推荐）
   - 本地安装：https://www.mongodb.com/try/download/community
   - 或使用 Docker：`docker run -d -p 27017:27017 --name mongodb mongo:latest`

3. **Redis**（可选，但推荐）
   - 本地安装：https://redis.io/download
   - 或使用 Docker：`docker run -d -p 6379:6379 --name redis redis:alpine`

### 可选组件

- **Node.js 18+**（仅前端开发需要）
- **Docker**（用于容器化部署）

## ⚙️ 配置设置

### 1. 创建 .env 文件

在项目根目录创建 `.env` 文件：

```bash
# 复制示例文件（如果存在）
cp .env.example .env

# 或手动创建
touch .env  # Linux/Mac
# 或使用文本编辑器创建
```

### 2. 最小配置（快速开始）

```env
# 大模型 API 密钥（至少配置一个）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
# 或
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxx
# 或
GOOGLE_API_KEY=AIzaSyxxxxxxxxxxxxxxxx

# 数据库配置（可选，不配置则使用文件存储）
MONGODB_ENABLED=false
REDIS_ENABLED=false

# 服务器配置
HOST=0.0.0.0
PORT=8000
DEBUG=true
```

### 3. 完整配置（推荐）

```env
# ==================== 服务器配置 ====================
HOST=0.0.0.0
PORT=8000
DEBUG=true
LOG_LEVEL=INFO

# ==================== 数据库配置 ====================
# MongoDB
MONGODB_ENABLED=true
MONGODB_HOST=localhost
MONGODB_PORT=27017
MONGODB_DATABASE=tradingagents
MONGODB_USERNAME=
MONGODB_PASSWORD=

# Redis
REDIS_ENABLED=true
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0
REDIS_PASSWORD=

# ==================== 大模型配置 ====================
# DeepSeek（推荐）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx

# 通义千问（阿里百炼）
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxx

# Google Gemini
GOOGLE_API_KEY=AIzaSyxxxxxxxxxxxxxxxx

# OpenAI
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx

# ==================== 数据源配置 ====================
# Tushare（A股数据，可选）
TUSHARE_TOKEN=your_token
TUSHARE_ENABLED=true

# Finnhub（美股数据，可选）
FINNHUB_API_KEY=your_key

# ==================== 安全配置 ====================
JWT_SECRET=change-me-in-production-please-use-random-string
ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000
ALLOWED_HOSTS=localhost,127.0.0.1

# ==================== 其他配置 ====================
TIMEZONE=Asia/Shanghai
```

## 🎯 启动方式

### 方式一：使用 Python 模块启动（推荐）

```bash
# 在项目根目录
python -m app
```

**优点**：
- ✅ 自动处理路径和编码问题
- ✅ 显示详细的启动信息
- ✅ 自动检查配置

**输出示例**：
```
🚀 Starting TradingAgents-CN Backend...
📍 Host: 0.0.0.0
🔌 Port: 8000
🐛 Debug Mode: True
📚 API Docs: http://0.0.0.0:8000/docs
```

### 方式二：直接运行 uvicorn

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 方式三：使用启动脚本

#### Windows
```cmd
# 使用批处理脚本
scripts\startup\start_backend.bat

# 或使用 PowerShell 脚本
python scripts\startup\start_backend_direct.py
```

#### Linux/Mac
```bash
# 使用 Shell 脚本
chmod +x scripts/startup/start_backend.sh
./scripts/startup/start_backend.sh

# 或使用 Python 脚本
python scripts/startup/start_backend_direct.py
```

### 方式四：生产环境启动

```bash
# 使用生产配置
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4 --no-access-log
```

## 🔍 常见问题

### 1. 端口被占用

**错误信息**：
```
ERROR: [Errno 48] Address already in use
```

**解决方法**：
```bash
# 方法1：更改端口
# 在 .env 文件中设置
PORT=8001

# 方法2：查找并关闭占用端口的进程
# Windows
netstat -ano | findstr :8000
taskkill /PID <PID> /F

# Linux/Mac
lsof -ti:8000 | xargs kill -9
```

### 2. 数据库连接失败

**错误信息**：
```
❌ MongoDB connection failed
```

**解决方法**：
```bash
# 检查 MongoDB 是否运行
# Windows
net start MongoDB

# Linux
sudo systemctl status mongod

# Mac
brew services list | grep mongodb

# 或使用 Docker
docker ps | grep mongo
```

**临时方案**：禁用数据库，使用文件存储
```env
MONGODB_ENABLED=false
REDIS_ENABLED=false
```

### 3. 缺少 API 密钥

**错误信息**：
```
⚠️ API密钥配置不完整
```

**解决方法**：
1. 在 `.env` 文件中配置至少一个大模型 API 密钥
2. 参考 [配置设置](#配置设置) 部分

### 4. 模块导入错误

**错误信息**：
```
ModuleNotFoundError: No module named 'app'
```

**解决方法**：
```bash
# 确保在项目根目录
pwd  # 应该显示项目根目录路径

# 确保已安装项目
pip install -e .

# 检查 Python 路径
python -c "import sys; print(sys.path)"
```

### 5. 编码问题（Windows）

**错误信息**：
```
UnicodeDecodeError: 'gbk' codec can't decode
```

**解决方法**：
- 使用 `python -m app` 启动（自动处理编码）
- 或在 PowerShell 中设置：
  ```powershell
  $env:PYTHONIOENCODING="utf-8"
  $env:PYTHONUTF8="1"
  ```

### 6. 依赖安装失败

**解决方法**：
```bash
# 升级 pip
python -m pip install --upgrade pip

# 使用国内镜像源
pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或使用 uv（更快）
uv pip install -e .
```
